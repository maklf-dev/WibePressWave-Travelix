TRAVELIX FLEX 3.0
=================

برای نصب مستقیم در وردپرس فقط فایل زیر را بارگذاری کنید:

travelix-flex.zip

مسیر نصب:
نمایش ← پوسته‌ها ← افزودن پوسته تازه ← بارگذاری پوسته

بعد از فعال‌سازی:
1) نمایش ← تنظیمات Travelix
2) یک‌بار «ذخیره تنظیمات» را بزنید.
3) لوگو و منوها را تنظیم کنید.
4) WooCommerce و فرم‌ساز موردنظر را فعال کنید.
5) صفحه «خانه» را در تنظیمات خواندن به‌عنوان صفحه نخست انتخاب کنید.

دو فایل راهنما را قبل از اجرای سایت Production مطالعه کنید:
- TRAVELIX-INSTALLATION-GUIDE-FA.md
- TRAVELIX-TAKEOFF-SUMMARY-FA.md

نکته: فایل Travelix-Flex-Complete-Package.zip را داخل وردپرس نصب نکنید؛
ابتدا آن را در کامپیوتر Extract کنید و سپس travelix-flex.zip را نصب کنید.
