# راهنمای نصب و استفاده Travelix Flex 3.0

## ۱. فایل درست برای نصب

در وردپرس فقط فایل زیر را نصب کنید:

```text
travelix-flex.zip
```

فایل Package شامل راهنما و خود ZIP قالب است و مستقیماً قالب وردپرس نیست.

## ۲. پیش‌نیاز پیشنهادی

- WordPress 6.4 یا جدیدتر
- PHP 7.4 یا جدیدتر؛ نسخه پشتیبانی‌شده و سازگار با هاست و افزونه‌های شما
- HTTPS فعال
- حداقل Memory Limit برابر 256MB برای WooCommerce و افزونه‌های چندزبانه
- تهیه Backup کامل فایل و دیتابیس

## ۳. نصب قالب

1. وارد `نمایش ← پوسته‌ها` شوید.
2. `افزودن پوسته تازه ← بارگذاری پوسته` را بزنید.
3. فایل `travelix-flex.zip` را انتخاب کنید.
4. نصب و سپس فعال‌سازی را بزنید.
5. وارد `نمایش ← تنظیمات Travelix` شوید.
6. یک‌بار دکمه «ذخیره تنظیمات» را بزنید تا مقادیر پیش‌فرض ثبت شوند.

اگر نسخه قبلی `travelix-persian-theme` نصب بوده، قالب در اولین فعال‌سازی تلاش می‌کند شماره، ایمیل، Form ID، شورت‌کد رزرو و تصاویر قبلی را منتقل کند.

## ۴. ساخت صفحه خانه و بلاگ

1. از `برگه‌ها ← افزودن` یک صفحه با عنوان «خانه» بسازید.
2. یک صفحه با عنوان «مجله سفر» بسازید.
3. وارد `تنظیمات ← خواندن` شوید.
4. نمایش صفحه اصلی را روی «یک برگه یکتا» قرار دهید.
5. صفحه نخست: «خانه».
6. برگه نوشته‌ها: «مجله سفر».

لازم نیست داخل صفحه خانه HTML وارد کنید. `front-page.php` خودکار اجرا می‌شود. اگر بعداً با ویرایشگر بلوکی یا Elementor محتوایی داخل خانه بگذارید، بعد از سکشن‌های قالب نمایش داده می‌شود.

## ۵. تنظیم لوگو و منوها

### لوگو

از `نمایش ← سفارشی‌سازی ← هویت سایت` لوگو، نام سایت، توضیح کوتاه و Site Icon را تنظیم کنید.

### منوها

در `نمایش ← فهرست‌ها` چهار جایگاه وجود دارد:

- منوی اصلی
- منوی فوتر
- منوی خدمات فوتر
- منوی قوانین

برای لینک سکشن‌های صفحه اصلی می‌توانید از پیوند سفارشی استفاده کنید:

```text
/#tours
/#destinations
/#about
/#process
/#reservation
/#stories
/#travel-request
```

## ۶. شناخت پنل Travelix

مسیر:

```text
نمایش ← تنظیمات Travelix
```

تب‌ها:

1. طراحی عمومی
2. هدر و نوار بالا
3. محتوای صفحه اصلی
4. کارت‌ها و کوئری‌ها
5. افزونه‌ها و اتصال‌ها
6. ریسپانسیو
7. فوتر
8. صفحات آینده

تنظیمات صفحه اصلی «شماره ترتیب» دارند. هرچه عدد کمتر باشد، بخش بالاتر قرار می‌گیرد. برای نمونه Hero با 10 قبل از تورها با 80 نمایش داده می‌شود.

## ۷. اتصال WooCommerce

### نصب

WooCommerce رسمی را از مخزن وردپرس نصب و فعال کنید. واحد پول، کشور و صفحات فروشگاه را در Wizard تنظیم کنید.

### ساخت مقصدها

1. `محصولات ← دسته‌بندی‌ها`.
2. هر کشور یا مقصد را یک دسته‌بندی بسازید.
3. برای آن Thumbnail انتخاب کنید.
4. حداقل یک محصول منتشرشده به مقصد وصل کنید.

کارت مقصد نام، تصویر، تعداد تور و لینک دسته‌بندی را خودکار می‌گیرد.

### ساخت ویژگی مدت سفر

1. `محصولات ← ویژگی‌ها`.
2. نام: «مدت سفر».
3. نامک پیشنهادی: `duration`.
4. ویژگی را به محصول اضافه کنید و مقدارهایی مثل «۷ روز» وارد کنید.

WooCommerce معمولاً Taxonomy این ویژگی را با نام `pa_duration` می‌سازد. در پنل Travelix، گزینه «نامک ویژگی مدت سفر» به‌طور پیش‌فرض همین مقدار است.

### محصولات نمایش‌داده‌شده

در تب «محتوای صفحه اصلی ← تورها» انتخاب کنید:

- محصولات ویژه
- جدیدترین محصولات
- محصولات یک دسته‌بندی

اگر «یک دسته‌بندی» را انتخاب کردید، نامک دسته را وارد کنید؛ مثلاً:

```text
turkey
```

### حالت کاتالوگ

در `افزونه‌ها و اتصال‌ها` گزینه Catalog Mode قرار دارد. پیش‌فرض خاموش است و خرید WooCommerce کار می‌کند. اگر روشن شود، خرید در کل سایت غیرفعال و دکمه‌ها به لینک درخواست رزرو هدایت می‌شوند.

## ۸. Gravity Forms یا فرم دیگر

### Gravity Forms

1. فرم را بسازید.
2. ID فرم را پیدا کنید.
3. در `محتوای صفحه اصلی ← فرم درخواست و تماس` منبع را Gravity Forms بگذارید.
4. ID را وارد و ذخیره کنید.

### Contact Form 7 یا افزونه دیگر

1. منبع فرم را «شورت‌کد دلخواه» بگذارید.
2. شورت‌کد کامل افزونه را در فیلد مربوط وارد کنید.

مثال:

```text
[contact-form-7 id="123" title="درخواست سفر"]
```

قالب استایل عمومی Input، Select، Textarea و Submit را روی فرم داخل جایگاه اعمال می‌کند، ولی تنظیمات تخصصی هر افزونه همچنان در خود افزونه است.

## ۹. Bookly و رزرو آنلاین

1. Bookly معتبر را نصب و تنظیم کنید.
2. فرم یا سرویس رزرو را بسازید.
3. شورت‌کد تولیدشده را کپی کنید.
4. در `محتوای صفحه اصلی ← رزرو آنلاین / Bookly` قرار دهید.
5. نمایش بخش را روشن کنید.

اگر فیلد شورت‌کد خالی باشد، بخش رزرو حتی در صورت روشن بودن نمایش داده نمی‌شود؛ بنابراین فضای خالی ایجاد نمی‌کند.

## ۱۰. WPML و دو زبان

1. WPML و String Translation را نصب کنید.
2. زبان فارسی و انگلیسی را فعال کنید.
3. بعد از ذخیره تنظیمات Travelix، وارد `WPML ← String Translation` شوید.
4. Domain یا Context با نام `Travelix Flex` را انتخاب کنید.
5. متن‌های هر فیلد را ترجمه کنید.

منوها، برگه‌ها، نوشته‌ها، محصولات و دسته‌بندی‌های محصول باید طبق روال WPML ترجمه شوند. سوییچر زبان در نوار بالایی از API رسمی WPML خوانده می‌شود و بدون WPML چیزی نمایش نمی‌دهد.

## ۱۱. شخصی‌سازی کارت محصول

در `کارت‌ها و کوئری‌ها ← کارت محصول / تور` می‌توانید تغییر دهید:

- رنگ پس‌زمینه
- Border Radius
- Padding محتوا
- اندازه عنوان
- ارتفاع تصویر
- فاصله بین کارت‌ها
- تعداد ستون دسکتاپ
- نمایش قیمت
- نمایش توضیح کوتاه
- نمایش مدت سفر
- ویژگی دوم محصول
- متن زیر قیمت
- متن خواندنی دکمه جزئیات

بهتر است برای یکپارچگی UI، ارتفاع تصاویر محصولات را ثابت نگه دارید و تصاویر با نسبت نزدیک 4:3 آپلود کنید.

## ۱۲. آیکن‌ها و مزیت‌ها

در بخش «مزیت‌ها و آیکن‌ها» و «معرفی و ویژگی‌ها» برای هر آیتم:

- آیکن
- عنوان
- توضیح

جداگانه قابل انتخاب است. SVGها داخل قالب هستند؛ بنابراین به Font Awesome یا سرویس خارجی وابسته نیستند.

## ۱۳. تنظیمات ریسپانسیو

تب Responsive شامل:

- فاصله کناری موبایل
- فاصله عمودی سکشن‌ها در تبلت و موبایل
- اندازه تیتر سکشن در تبلت و موبایل
- اندازه و ارتفاع Hero در تبلت و موبایل
- ارتفاع تصویر کارت‌ها در موبایل
- کاهش انیمیشن‌ها

چیدمان پایه در 960px و 640px به‌ترتیب به تبلت و موبایل تبدیل می‌شود. کارت مقصد در موبایل به نوار افقی قابل لمس تبدیل می‌شود تا تصویرها خیلی کوچک نشوند.

## ۱۴. صفحات آینده

نسخه فعلی تمرکز اصلی را روی Home دارد، ولی از حالا این موارد آماده‌اند:

- `page.php` برای برگه‌ها
- `single.php` برای نوشته تکی
- `archive.php` و `search.php`
- `woocommerce.php`
- هدر و فوتر سراسری
- Elementor Header/Footer Locations
- تنظیم ارتفاع Hero داخلی، عرض نوشته و ستون آرشیو در تب «صفحات آینده»

گزینه‌های صفحات آینده ذخیره می‌شوند تا هنگام اضافه‌کردن قالب اختصاصی تور، مقصد، تماس و درباره ما دوباره معماری تنظیمات تغییر نکند.

## ۱۵. امنیت و نگه‌داری

- فقط افزونه‌ها و قالب‌های اصلی و لایسنس‌دار نصب کنید.
- از قالب یا افزونه Nulled استفاده نکنید.
- ویرایشگر فایل داشبورد را در `wp-config.php` غیرفعال کنید:

```php
define( 'DISALLOW_FILE_EDIT', true );
```

- `WP_DEBUG` را روی سایت Production خاموش نگه دارید و Log خطا را فقط موقتاً روی Staging فعال کنید.
- دسترسی پیشنهادی فایل‌ها 644 و پوشه‌ها 755 است.
- قبل از Update اصلی، Backup فایل و دیتابیس بگیرید.
- WordPress، WooCommerce، WPML، Bookly و فرم‌ساز را منظم به‌روزرسانی کنید.
- برای فرم‌ها CAPTCHA یا Anti-Spam معتبر و Rate Limit مناسب فعال کنید.

## ۱۶. تست قبل از انتشار

1. قالب را ابتدا روی Staging نصب کنید.
2. یک محصول ساده و یک محصول متغیر بسازید.
3. محصول تخفیف‌دار و بدون قیمت را تست کنید.
4. ارسال فرم و ایمیل اعلان را تست کنید.
5. رزرو Bookly را تا صفحه تأیید تست کنید.
6. سبد خرید و Checkout را با یک پرداخت آزمایشی بررسی کنید.
7. نسخه فارسی و انگلیسی را باز کنید.
8. منوی چندسطحی، جستجو و سبد خرید موبایل را تست کنید.
9. Lighthouse را برای Performance، Accessibility و SEO اجرا کنید.
10. کش افزونه، سرور و CDN را پاک کنید.

## ۱۷. عیب‌یابی سریع

### صفحه اصلی طرح قالب را نشان نمی‌دهد

- صفحه «خانه» را در Settings → Reading انتخاب کنید.
- کش را پاک کنید.
- مطمئن شوید فایل `front-page.php` داخل ریشه قالب است.

### تورها نمایش داده نمی‌شوند

- WooCommerce فعال باشد.
- محصول Published باشد.
- اگر منبع روی Featured است، محصول را Featured کنید.
- اگر منبع روی Category است، نامک دسته را دقیق وارد کنید.

### مدت سفر نمایش داده نمی‌شود

- ویژگی به محصول وصل و Visible باشد.
- نامک تنظیم‌شده با Taxonomy واقعی برابر باشد؛ معمولاً `pa_duration`.

### فرم نمایش داده نمی‌شود

- افزونه فرم فعال باشد.
- ID یا شورت‌کد صحیح باشد.
- Shortcode را همراه با براکت‌ها وارد کنید.

### ترجمه پنل دیده نمی‌شود

- String Translation فعال باشد.
- تنظیمات Travelix را یک‌بار دوباره ذخیره کنید.
- Domain با نام `Travelix Flex` را بررسی کنید.

### ظاهر بعد از تغییر تنظیمات عوض نمی‌شود

- کش مرورگر، افزونه کش، هاست و CDN را پاک کنید.
- View Source را بررسی کنید که فایل `main.css` نسخه جدید دارد.
